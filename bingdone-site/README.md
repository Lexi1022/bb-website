# Bingdone 网站便携导出

## 使用方式

- 根目录 `index.html` 为中文版；`en/index.html` 为英文版。
- 上传本文件夹中的静态页面、`_astro/` 和根目录图片到服务器的网站目录即可；中英文链接和网站资源均使用相对路径。
- 本地可打开 `index.html` 查看。推荐在本目录执行 `python -m http.server 8000`，再打开浏览器访问该端口；浏览器的安全限制可能使直接打开文件时的剪贴板复制功能不可用，但仍可下载需求清单。
- 邮件和电话链接调用访客设备上的邮件、拨号应用，不是服务器自动发送功能。

## 文件结构

- 根目录与 `en/`：可部署的 HTML。
- `_astro/`：编译后的 CSS/JavaScript（如有）；其他脚本由 Astro 内联在 HTML 中。
- 根目录图片：发布资源，保留原有文件名。
- `public/`：全部原始网站公共资源，保留源项目结构。
- `src/pages/`：中英文 Astro 源码，已改用相对资源和页面链接。
- `package.json`、`package-lock.json`、`astro.config.mjs`：构建配置和固定依赖。
- `site-metadata.json`：可公开的站点元数据。
- `FILE_MANIFEST.txt`、`FILE_MANIFEST.json`：每个文件的相对路径；JSON 含大小与 SHA-256（清单自身的哈希标为 null，以避免循环）。
- `EXPORT_CHECKS.json`：安全清理和本地引用检查结果。

## 源码与构建

已提供可直接部署的静态成品，无需先安装依赖。如需修改 Astro 源码，可执行 `npm ci` 和 `npm run build`，生成新的 `dist/`。Astro 默认生成的编译资源链接可能以斜杠开头，因此重新构建后若要部署到子目录，需要再次相对化资源引用，或配置与实际部署目录一致的 Astro base。

## 导出边界

保留现有页面、公开公司联系方式、品牌 Logo、工厂实拍、产品图、概念图、CSS、内联脚本、产品数据和语言元数据。未包含系统字体文件，因为网站依赖访客设备的系统字体，且未使用远程字体。没有独立网站文档、后台数据库或已保存的客户询价记录。

不包含 Git 历史、node_modules、环境文件、访问令牌、账户信息、部署身份文件、开发缓存、工作提示、截图附件及本地电脑路径。已移除原 ChatGPT 托管地址的页面元数据依赖。公开电话、邮箱和地址是网站内容，并非客户数据。

原产品宣传图内的中文仍保留，英文页面说明文字已经翻译。大陆可达性取决于新托管商和网络线路；此导出包不包含托管、DNS、备案或证书服务。
